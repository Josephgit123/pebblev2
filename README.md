Pebble Compiler
Pebble is a simple programming language and compiler built from scratch using JavaScript. The compiler translates Pebble source code into x86-64 assembly language, assembles and links it using NASM and GCC, and produces a Windows executable.
Compiler Workflow
Pebble Source Code (.peb)
          ↓
        Lexer
          ↓
        Parser
          ↓
   Semantic Analyzer
          ↓
    Code Generator
          ↓
   x86-64 Assembly (.asm)
          ↓
         NASM
          ↓
      Object File (.obj)
          ↓
          GCC
          ↓
   Executable (.exe)

Features
The Pebble compiler currently supports:
- Integer variables using hold
- Arithmetic operations
  - Addition +
  - Subtraction -
  - Multiplication *
  - Division /
- Variable assignment
- Comparison operations
  - Greater than >
  - Less than <
  - Greater than or equal to >=
  - Less than or equal to <=
  - Equal to ==
  - Not equal to !=
- Conditional statements
  - if
  - else
- while loops
- Functions
- Function parameters
- Function calls
- Return values
- Output using mould()
- User input using take()
- Semantic error detection
- Generation of x86-64 assembly
- Windows executable generation
Pebble Syntax
Variables
hold a = 10;
hold b = 20;

mould(a);
mould(b);
Arithmetic Operations
hold a = 10;
hold b = 3;

mould(a + b);
mould(a - b);
mould(a * b);
mould(a / b);
Expected output:
13
7
30
3
Pebble currently uses integer arithmetic, so division returns the integer quotient.
Input
Pebble uses take() to receive integer input from the user.
hold age = 0;

take(age);

mould(age);
Example:
Input:
25

Output:
25
If-Else
hold a = 10;
hold b = 20;

if (a > b) {
    mould(a);
} else {
    mould(b);
}
Output:
20
While Loop
hold i = 1;

while (i <= 5) {
    mould(i);
    i = i + 1;
}
Output:
1
2
3
4
5
Functions
mould add(a, b) {
    make a + b;
}

hold result = add(10, 20);

mould(result);
Output:
30
Example Compilation
For a Pebble program:
hold a = 10;
hold b = 20;

mould(a + b);
Run:
node main.js examples/add.peb
The compiler performs the following stages:
add.peb
   ↓
Lexical Analysis
   ↓
Parsing
   ↓
Semantic Analysis
   ↓
Code Generation
   ↓
add.asm
   ↓
NASM
   ↓
add.obj
   ↓
GCC
   ↓
add.exe
The generated executable is then executed automatically.
Generated Files
When a Pebble program is compiled:
.asm
The assembly file generated by the Pebble compiler.
Example:
examples/add.asm
.obj
The object file generated by NASM.
Example:
examples/add.obj
.exe
The final Windows executable linked using GCC.
Example:
examples/add.exe

Requirements
The following tools must be installed and available in the system PATH:
- Node.js
- NASM
- GCC
Check the installations using:
node --version
nasm --version
gcc --version
Running the Compiler
Open Command Prompt in the project directory:
cd /d E:\pebble
Compile and run a Pebble program:
node main.js examples/input.peb

Current Limitations
- Integer values only
- No floating-point numbers
- Maximum of four function arguments
- No arrays
- No strings
- No classes or objects
- Basic error messages
- Windows-focused code generation

- Floating-point number support
- String support
- Arrays and collections
- Improved indentation-based syntax
- Better compiler error messages with line numbers
- More data types
- Payment-processing-specific language features
- Optimization stage
- Support for additional operating systems
- Self-hosting and compiler bootstrapping
